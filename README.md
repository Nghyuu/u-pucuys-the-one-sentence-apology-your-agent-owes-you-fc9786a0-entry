A program that writes one single-sentence apology — an AI agent owning up to the person it works for — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Run with `MAKEFUN_OUTPUT_DIR` set; the program throws if it is unset. Node stdlib only.
